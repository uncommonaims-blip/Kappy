# Kappy

A mobile-first care-circle coordination app (working name).

## Vision
Help caregivers, families and trusted community members coordinate compassionate, dependable care.

## Initial scope
- Private care circles with roles
- Shared shifts and coverage requests
- Daily care routines and handoff notes
- Caregiver and client profiles

## Development
This repository starts as a prototype. No real client or medical data should be entered until authentication, authorization, secure storage, and privacy controls have been implemented and reviewed.

See `docs/PRODUCT.md` for product direction and `docs/ARCHITECTURE.md` for implementation notes.
